기본 관리자 비밀번호(admin1234)를 쓰고 있습니다. 먼저 바꿔 주세요.

초기 설정

사이트

용어는 키오스크·세대 웹 화면에 그대로 나옵니다. 아파트라면 '동'·'호', 캠퍼스라면 '건물'·'호실'.

건물

건물 번호(1~999)는 세대 계정 아이디 앞부분이라 만든 뒤에는 바꿀 수 없습니다. 호실은 층×100+호 형식 범위(예: 101 ~ 614)로 적고, 없는 호실과 범위 밖 추가 호실은 쉼표로 적습니다 (예: 404, 501~514).

보관소·배송

보관함 1칸(또는 배송 불가 보관함 문 1개)에 물품 1개만 들어갑니다. 배송 시간 예약은 10분 단위, 칸마다 2자리입니다.

미리보기

입력하면 만들어질 계정 수와 호실 안내가 여기에 나옵니다.

세대 계정

계정 아이디는 건물번호-호실, 초기 비밀번호는 1234 입니다.

보관 현황

보관·배송 중인 물품과 보관함 사용량입니다. 10초마다 새로 불러옵니다.

시연 모드예약 가능 시간(30분)·예약 칸 발행 대기(칸 시작 15분 전)를 건너뛰고 바로 배송을 발행합니다. 로봇은 물품이 2개 모여야 출발합니다.

코드로 수령 처리

세대인이 키오스크를 쓰기 어려울 때, 세대 웹의 인증코드 6자리로 물품을 꺼내 줍니다.

작업 기록

관리자 작업 기록입니다. '전체 기록'을 켜면 보관·수령 기록도 함께 봅니다.

전체 재설정

현장 설정, 세대 계정, 물품 기록을 모두 지우고 초기 설정 전 상태로 돌립니다. 되돌릴 수 없습니다.

보관·배송 중인 물품이 하나라도 있으면 재설정할 수 없습니다. 작업 기록과 관리자 계정은 남습니다.

관리자 비밀번호

영문과 숫자를 섞어 8자 이상. 바꾸면 다른 곳의 관리자 로그인은 끝납니다.

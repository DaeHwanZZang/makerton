보관소 배송 연동

택배 접수는 키오스크에서, 로봇 운행은 FMS에서 관리합니다. 보관소 출발부터 복귀까지 같은 로봇을 예약합니다.

입력 키오스크 · 출력 키오스크 · 세대 웹

현장과 목적지 연결

배송 1건은 트레이 반납 뒤 충전 스테이션 도킹까지이며, 그동안 같은 로봇을 예약합니다. 보관소에는 트레이 반납 시점에 완료를 알립니다. 도킹한 로봇은 충전량이 기준 이상이면 다음 배송을 받습니다.

배송은 물품 2개가 모이면 출발하며 두 트레이(TRAY_A·TRAY_B)에 하나씩 싣습니다. 시뮬레이터는 지정한 시간의 PICK·DROP 액션 완료를 적재·인도로 간주합니다. 픽업스테이션(맵의 ＋ → 픽업스테이션)과 각 세대의 목적지를 먼저 등록하세요.

세대 (동-호)FMS 목적지

배송 현황

오류가 발생한 배송은 로봇 예약을 유지합니다. 로봇을 점검하고 적재물을 대조한 뒤 복귀를 요청하세요. 진행 중인 작업의 취소는 FMS 작업 게시판에서 합니다.

물품 장부

FMS가 물품마다 부여한 ID와 현재 위치입니다. 상태는 로봇의 PICK·DROP 완료 보고로 확인한 값이며 실제 적재 센서 검출이 아닙니다. 확인 필요 물품은 실물을 확인한 뒤 정정하세요.

물품 ID / 접수번호세대상태로봇·트레이마지막 확인 위치

적재물 대조 후 복귀

이미 인도한 물품만 선택하세요. 선택하지 않은 잔여 물품은 로봇에 남아 있으며 보관소 도착 후 재입고됩니다.
